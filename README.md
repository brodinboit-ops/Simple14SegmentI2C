This is a very simple library designed to control I2C 14SegmentDisplays

**Note this project was written by the help of an AI so expect some issues**

1. How to Use:
   
   To use this library, include it as a .zip library in the arduino IDE, it should work automatically

3. Whats special about it:
   
   14 Segment displays are known to be hard to control with arduino IDE and their libraries often take up a lot of storage, making them annyoing to work with. This library solves MOST of those problems and
   makes work with 14 segment displays A LOT easier.

5. Commands:
   
   This library is designed to work very similarly in a way that the LCD-I2C library works. It is designed to print things. Note: MAKE SURE TO CALL THE DISPLAY and CLEAR functions, it wont work
   otherwise.


   Have FUN!!!
